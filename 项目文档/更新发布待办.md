# 更新发布待办

## 当前轻量版检查更新

- GitHub 项目地址：https://github.com/HereisFrank9527/AiSync
- 前端设置页已增加“应用更新”区块。
- 当前实现读取 GitHub Releases latest：
  `https://api.github.com/repos/HereisFrank9527/AiSync/releases/latest`
- 轻量版只比较版本、展示 Release 信息，并打开安装包或发布页，不做自动安装。

## 你每次发布前需要做

1. 修改 `frontend/src-tauri/tauri.conf.json` 里的 `version`。
2. 运行 `cd frontend && npm run tauri build`。
3. 到 GitHub 创建 Release，tag 建议使用 `v版本号`，例如 `v0.1.5`。
4. 上传安装包：
   - `frontend/src-tauri/target/release/bundle/nsis/AiSync_<版本号>_x64-setup.exe`
   - 可选上传 MSI：`frontend/src-tauri/target/release/bundle/msi/`
5. Release 正文写清楚变更、已知问题和升级注意事项。
6. 发布后打开应用设置页，点击“检查更新”验证能看到新版本。

## 后续升级到自动更新需要做

1. 接入 Tauri v2 updater 插件。
2. 生成 updater 签名密钥。
3. 私钥放到 GitHub Actions Secrets，公钥写入 `tauri.conf.json`。
4. 打包时生成 updater artifacts 和签名。
5. Release 上传 `latest.json`、更新包和 `.sig`。
6. 前端从“打开下载页”升级为“下载并安装，然后重启”。

## 注意

- GitHub Releases 的 tag 要能和应用版本对应，推荐 `v0.1.5` 这种格式。
- 如果 Release 里没有 exe/msi/zip，前端仍会显示发布页入口，但可能没有“下载安装包”按钮。
- 当前检查更新依赖访问 GitHub；离线环境会显示请求失败。
